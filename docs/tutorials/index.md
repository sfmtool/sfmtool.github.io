# Tutorials

Each tutorial is a lesson to follow from start to finish, with a result to
see at each step. Take them in this order: the second works on the
reconstruction the first makes.

- [Getting Started](getting-started.md): make a 3D reconstruction from 85
  photographs of a toy and open it in SfM Explorer.
- [Viewing 3D Point Tracks](point-tracks.md): follow one 3D point to the
  photographs that see it, and move around the scene in SfM Explorer.
